# 책 패널 UI 에셋 (픽셀아트, 16px 기준)

아이콘·텍스트 없이 배경만 제작했습니다. 모든 PNG는 투명 배경입니다. 책 본체는 3조각(왼쪽 페이지 + 책등 + 오른쪽 페이지)이고, 책등은 가로 폭 8px로 고정합니다(가운데에서 늘어나 뭉개지는 것을 막기 위해).

## 조합 방법 (책 본체)

1. 왼쪽 페이지, 책등, 오른쪽 페이지를 가로로 이어 붙입니다. 두 페이지는 같은 폭으로 둡니다.
2. 탭은 책보다 **먼저(뒤에)** 그립니다. 왼쪽 4px가 표지 아래로 들어가야 합니다.
3. 탭은 오른쪽 페이지의 바깥쪽 가장자리에 세로로 쌓습니다. 기본 간격은 탭 높이 20px + 2px입니다. 책 높이를 꽉 채울 필요는 없고, 위쪽부터 필요한 개수만큼만 두면 됩니다.
4. 선택된 탭은 normal을 selected 스프라이트로 교체합니다.

탭 아이콘 안전 영역은 **12×12px**입니다. 책 표지에 가려지는 왼쪽 4px를 뺀 보이는 영역의 중앙에 둡니다. normal은 탭 왼쪽에서 (x=12, y=10), selected는 (x=14, y=10)입니다.

## 페이지 넘김 연출 규칙

설정한 페이지 폭을 W라고 할 때(스프라이트 기준 책등 중심에서 반대편 표지 안쪽까지의 거리), 아래 순서로 총 9프레임을 한 프레임당 약 45ms로 재생합니다(약 0.4초).

1. **넘어가는 페이지의 힌지(축)**는 책등의 가운데입니다.
2. 프레임 k = 0~8에서 p = (k+1)/10으로 두고, 폭 = `round(W × |cos(π × p)|)` (정수 픽셀)로 구합니다. 소수 단위 Scale은 쓰지 않습니다(도트 크기가 프레임마다 달라져 뭉개짐).
3. 변형은 폭 비율이 0.8 이상이면 leaf_0, 0.45~0.8이면 leaf_1, 0.45 미만이면 leaf_2를 씁니다. k=4(가장 얇은 순간)는 leaf_edge(폭 6px)를 씁니다.
4. k=0~3은 출발한 쪽(앞으로 넘기면 오른쪽, 뒤로 넘기면 왼쪽)에, k=5~8은 반대편에 놓고, 반대편은 좌우 반전(Scale X = -1, 정수 반전이라 도트가 깨지지 않음)합니다.
5. 페이지는 `round(4 × sin(π × p))` 픽셀만큼 위로 들어 올립니다. 책 위쪽 가장자리를 살짝 넘어가도 괜찮습니다.
6. 그림자(shadow_strip)는 넘어가는 페이지의 바깥쪽 가장자리 바깥에 붙입니다. 반대쪽에 놓을 때는 좌우 반전하고, 페이지 안쪽 경계를 넘으면 잘라냅니다. k=4에서는 양쪽에 둡니다.

**내용 교체 타이밍(페이지 위가 빈 종이일 때)**: 넘어가는 페이지가 거의 전체를 덮는 프레임에서 아래 내용을 바꿉니다.
- 앞으로 넘김: 오른쪽 페이지 내용은 k=0에서, 왼쪽 페이지 내용은 k=8에서 교체
- 뒤로 넘김: 왼쪽 페이지 내용은 k=0에서, 오른쪽 페이지 내용은 k=8에서 교체

멀리 있는 탭으로 이동할 때는 탭 사이 거리만큼 이어서 넘기고, 넘기는 동안은 탭 입력을 잠그거나 마지막 입력만 예약합니다.
선택된 탭 스프라이트는 k=0에서 바로 교체합니다.
