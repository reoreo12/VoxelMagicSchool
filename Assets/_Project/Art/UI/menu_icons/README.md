# menu_icons

임포트(전부): Point, 압축 없음, Full Rect, PPU 16, Simple.

## buttons/ (16x16) — 왼쪽 위 메뉴 버튼
- btn_book_{normal,hover,pressed}.png : 책 (사용자 제공 아이콘, hover=밝게, pressed=어둡게)
- btn_bag_{normal,hover,pressed}.png  : 가방 (사용자 제공 아이콘, 같은 방식)
- 배경이 없는 아이콘이라 Button의 Sprite Swap으로 상태 스프라이트를 바꿔 쓴다.

## tab_icons/ (12x12) — 책 사이드 탭용, 탭 색에 상관없이 쓰는 크림색 + 어두운 외곽선
- tab_icon_spell.png    : 마법 스펠 (반짝이는 별)
- tab_icon_circle.png   : 마법진 종류 (원형 마법진)
- tab_icon_settings.png : 환경 설정 (톱니바퀴)
- tab_icon_menu.png     : 메뉴 (문 + 나가기 화살표)
- 탭 스프라이트(20x20 / 선택 24x20)의 안전 영역 12x12 위에 올린다.
