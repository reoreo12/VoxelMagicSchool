# score_ui — 예상 점수 숫자 UI

실기·필기 예상 점수를 숫자 스프라이트로 조합해 보여 주는 에셋. 마커로 쓴 듯한 붉은 손글씨 느낌의 도트 숫자와 아래 두 줄 밑줄.
(참고 이미지의 모양을 따라 그리지 않고 도트로 새로 그렸다.)

## 파일

| 파일 | 크기 | 설명 |
|---|---|---|
| digits/score_digit_0~9.png | 9×12 | 숫자 한 글자씩 (위쪽 절반이 오른쪽으로 1px 기울어 있음) |
| score_digits_sheet.png | 90×12 | 0~9를 한 줄로 이은 시트 (칸 9×12, Sprite Multiple로 자르기) |
| underline/score_underline_1~4.png | (9n+4)×9 | n자리 숫자용 밑줄. 위 줄이 길고 아래 줄이 짧음 |
| _preview/ | | 확대 미리보기 (게임에서 쓰지 않음) |

## Unity 임포트
Point(no filter), Compression None, Mesh Type Full Rect, PPU 16, Simple. 시트는 Sprite Mode Multiple, Grid By Cell Size 9×12.

## 조합 규칙
- 숫자 칸 폭은 9px로 고정, 칸 사이 간격 0(글자 사이는 자연히 1px 비어 보임). 자릿수 n이면 숫자 폭 = 9n.
- 밑줄은 숫자 가로 양옆으로 2px씩 튀어나오게 둔다(폭 9n+4). 숫자 아래 바로 붙이면 되고, 밑줄 위쪽 줄은 숫자 하단과 약 0~1px 간격.
- 밑줄은 기울기가 있어 9-slice로 늘릴 수 없다. 1~4자리는 준비된 4개를 쓰고, 5자리 이상이 필요하면 새로 만든다.
- 숫자와 밑줄은 정수 픽셀에 배치한다(홀수 폭 + 중앙 피벗이면 0.5px 어긋나니 피벗/앵커에 주의).
- 자릿수가 바뀌면 숫자 오브젝트를 생성/제거하고 밑줄 스프라이트를 교체한다.

## ver2 (더 휘날리는 기울기) — `v2/`

| 파일 | 크기 | 설명 |
|---|---|---|
| v2/digits/score_digit_0~9.png | 11×12 | 아래에서 위로 갈수록 오른쪽으로 최대 3px 기울어진 숫자 |
| v2/score_digits_sheet.png | 110×12 | 0~9 시트 (칸 11×12, Grid By Cell Size 11×12) |
| v2/underline/score_underline_1~4.png | (9n+6)×10 | 아랫줄이 윗줄보다 길고 오른쪽으로 치켜 올라가며 끝나는 두 줄 |

- 조합: **칸 간격(spacing) -2px**로 겹쳐 배치한다(칸 폭 11, 피치 9). 이렇게 하면 글자 사이가 1px 비어 보인다. 자릿수 n이면 숫자 전체 폭 = 9n+2.
- 밑줄은 숫자 가로 중앙에 맞춰 양옆 2px씩 튀어나오게 둔다(폭 9n+6). 3·4자리 밑줄은 윗줄이 먼저 시작해 먼저 끝나고, 아랫줄은 5px 늦게 시작해 윗줄보다 7px 더 오른쪽에서 끝난다. 1·2자리는 폭이 좁아 윗줄이 늦게 시작하는 이전 모양 그대로다.
- 1자리 밑줄은 폭이 좁아 윗줄이 짧은 점처럼 보인다. 마음에 들지 않으면 1자리용만 따로 다듬는다.
- ver1과 ver2는 섞어 쓰지 않는다. 비교 이미지: `_preview/score_v1_v2_compare_4x.png`.
