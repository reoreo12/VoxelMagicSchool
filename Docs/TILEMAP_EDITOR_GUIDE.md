# 타일 맵 에디터 사용법 (단계별)

> 2026-11-06 · 설계: `DESIGN_TILEMAP.md` (11장 여러 맵·불러오기·바닥 종류)
> **흐름: 에디터 씬에서 새 맵 만들기 → 칠하기 → 굽기(파일로 저장) → 게임 씬에 구운 프리팹 놓기.**
> 굽기는 플레이 전에 에디터에서 한 번만 한다. 게임은 저장된 파일만 쓴다. 고칠 때는 다시 불러와 칠하고 다시 굽는다.

---

## 0. 처음 한 번만 (이미 되어 있음 — 새 PC·새 타일 팩일 때만)
| 순서 | 메뉴 `VoxelMagic/타일 맵/…` | 하는 일 |
|---|---|---|
| 1 | `타일 팩 임포트 설정 적용 (전체)` | 타일 PNG를 도트용 설정으로 (Point, 압축 없음, PPU 32) |
| 2 | `farm 타일·Rule Tile·팔레트 만들기` | farm 타일 48개, Rule Tile 3개, 팔레트 Farm (있으면 덮어쓸지 묻는다) |
| 3 | `바닥 종류 표 만들기·채우기 (farm)` | 바닥 종류 6개(풀·흙·진흙·짚·돌·나무판)와 타일 → 종류 표 (있으면 빠진 줄만 더함) |

## 1. 에디터 씬 열기
1. 메뉴 **`VoxelMagic/타일 맵/타일 맵 에디터 씬 열기`**
   - 저장 안 한 씬이 있으면 저장할지 먼저 묻는다
   - 씬 `Scenes/Tools/TileMapEditor`와 **도구 창**이 함께 열린다
2. 도구 창만 다시 열 때: **`VoxelMagic/타일 맵/타일 맵 에디터 창`** (창은 다른 창 옆에 끌어다 붙여 두면 편하다)

### 씬 구성
```
Directional Light      해 (농장과 같은 값)
Maps                   모든 맵이 여기 아래
 └ Map_<이름>          맵 하나 = 루트 하나. 옮기면 맵 전체가, 끄면 맵 전체가 숨겨짐
    ├ Grid > Paint     칠하는 층 (Tilemap)
    └ <이름>_Floor     구운 바닥 (구운 뒤에 생김)
Compare                비교용: Center(카메라·치비·1 m 상자), East(연못) — 작업 대상 맵을 따라감
```

### 도구 창 구성 (위에서 아래로)
| 영역 | 내용 |
|---|---|
| 맵 목록 | 씬의 모든 맵. ☑ = 보이기, ▶ = 지금 작업 대상, `[선택]` |
| 새 맵 | 이름·크기·바탕 타일로 새 맵 만들기 |
| 구운 맵 불러오기 | 구워 둔 맵을 다시 불러와 고치기 |
| 작업 대상: <이름> | 아래 기능은 모두 **이 맵에만** 적용 |
| 맵 | 맵 이름, 굽기 결과 경로 |
| 칸 크기 | 한 칸 크기(모든 맵 공용), 후보 버튼 |
| 굽기 | 굽기 버튼, 결과, 바닥 종류 표, 구운 상태로 되돌리기 |
| 보기 | 칠하기 시작, 칠하기 / 구운 바닥 전환 |
| 해 | 해 높이·방향 (그림자 확인용) |

## 2. 새 맵 만들기
1. 도구 창 **새 맵** 영역을 편다
2. **이름**: 굽기 결과 폴더·프리팹 이름이 된다 (예: `FarmMain`). 영문·숫자 권장
   - 씬의 다른 맵이나 이미 구운 폴더(`Art/Map/Baked/<이름>`)와 같으면 노란 경고가 뜨고 만들 수 없다 → 이름을 바꾼다
3. **크기 (가로 × 세로 칸)**: 기본 40 × 40. 나중에 바깥으로 더 칠해도 된다
4. **바탕 타일**: 기본 `meadow_grass`(풀)로 맵 전체를 채운다. 비우면 빈 맵
5. **다른 맵 숨기기**: 켜 두면 다른 맵이 숨겨져 새 맵만 보인다
6. **새 맵 만들기** 클릭
   - 기존 맵들 오른쪽(+X)에 4칸 띄워 놓인다 (숨긴 맵과도 안 겹침)
   - 바로 선택되고, Tile Palette가 열리며 칠하기 상태가 된다
   - 잘못 만들었으면 **Ctrl+Z** 한 번 (숨겼던 맵도 되돌아옴)

---

## 3. 칠하기
1. 작업 대상 맵에서 **보기 → "칠하기 시작"** (새 맵·불러오기 직후에는 자동)
   - Tile Palette 창이 열리고 팔레트 **Farm**, 칠할 대상 **그 맵의 Paint**가 골라진다
   - 다른 맵을 선택하면 칠할 대상도 그 맵으로 바뀐다
2. 팔레트 구성
   - **1줄**: 바닥 12종 (맨 앞 `meadow_grass` = 바탕 풀)
   - **2줄**: **Rule Tile 3개** — 흙(`RT_dark_garden_soil`), 진흙 길(`RT_muddy_farm_path`), 짚(`RT_straw_covered_ground`)
   - **아래 3줄**: 경계 낱장 (자동 경계가 마음에 안 드는 칸을 손으로 고칠 때)
3. 순서: 바탕 풀 위에 **Rule Tile로 흙·길·짚 영역만** 칠한다 → 경계는 저절로 붙는다
4. 씬 뷰에서 쓰는 단축키

   | 키 | 도구 | 쓰는 법 |
   |---|---|---|
   | B | 붓 | 클릭·끌기로 한 칸씩 |
   | U | 사각형 채우기 | 끌어서 사각형 |
   | G (→ Shift+G 권장) | 채우기 | 클릭한 칸과 **같은 타일로 상하좌우 이어진** 영역을 한 번에 (아래 "채우기 동작") |
   | D | 지우개 | 클릭·끌기로 지우기 |
   | I | 스포이드 | 칠한 칸에서 타일 집기 |
   | Ctrl+Z | 되돌리기 | |
5. 칠한 뒤 **Ctrl+S**로 씬 저장 (칠한 칸은 씬에 저장된다)

### G 단축키 충돌
- Unity 6 기본 설정에서 G는 `Grid Painting/Fill`(채우기)과 `Tools/Cycle Tool Modes`(도구 모드 전환)에 함께 걸려 있어 누르면 "Shortcut Conflict" 창이 뜬다
- **Edit > Shortcuts…** → `Grid Painting/Fill` 검색 → 단축키를 **Shift+G**로 (2026-11-06 확인: 기본 설정에서 비어 있음). PC마다 하는 Unity 사용자 설정이라 커밋되지 않는다
- 또는 Tile Palette 창 위쪽 **페인트통 아이콘**

### 채우기 동작 (2026-11-06 실제로 돌려 확인)
- 클릭한 칸과 **같은 타일**이 **상하좌우로** 이어진 칸을 모두 손에 든 타일로 바꾼다
- 흙 Rule Tile은 경계 그림이 달라도 **같은 타일**로 친다 → 흙 덩어리를 클릭하고 짚으로 채우면 그 덩어리 전체(경계 칸 포함)가 짚이 된다. 떨어진 다른 흙 덩어리는 그대로
- **테두리 안 채우기**: 흙으로 닫힌 고리를 그리고, 흙을 든 채 고리 **안쪽 풀**을 클릭 → 안쪽 풀만 흙이 되어 꽉 찬 사각형
  - 모서리 한 칸이 빠져 **대각선으로만** 이어져도 새지 않는다 (상하좌우만 따짐)
  - 변에 **한 칸이라도 틈**이 있으면 바깥 풀까지 이어져 **맵 전체가 흙**이 된다 → 바로 **Ctrl+Z**

### 칠할 때 알아 둘 것
- 경계 그림이 칸 가운데를 지나므로 **칠한 영역이 둘레로 반 칸씩 줄어 보인다** (6×6을 꽉 찬 흙으로 보이려면 8×8)
- **1칸 폭 줄**, **대각선으로만 닿는 칸**은 맞는 경계 그림이 없어 네모나게 끊긴다 → 2칸 이상 폭으로
- 흙·길·짚끼리 바로 맞닿으면 사이에 풀 테두리가 생긴다 (그림 세트가 "풀 → X"뿐)
- 맵 바깥(빈칸)에 닿은 흙·길에도 경계가 생긴다 → 맵 끝까지 이어질 길은 한 칸 더 칠한다

## 4. 여러 맵 다루기
| 하고 싶은 것 | 방법 |
|---|---|
| 작업 대상 바꾸기 | 맵 목록 `[선택]`, 또는 Hierarchy에서 `Map_…`이나 그 안의 아무 오브젝트 선택 |
| 숨기기 / 보이기 | 맵 목록 ☑ 끄기·켜기 (= `Map_…` 루트 켜기·끄기). 칠한 칸·구운 바닥이 함께 |
| 다른 맵 모두 숨기기 | 맵 목록 아래 **"작업 대상 말고 다른 맵 모두 숨기기"** |
| 옆으로 치우기 | `Map_…` 루트의 Transform Position을 바꾼다 (구운 바닥도 따라감). 회전·배율은 바꾸지 않는다 |
| 이름 바꾸기 | 작업 대상의 **맵 이름** 칸 (루트 이름도 `Map_<새 이름>`으로). 이미 구운 맵이면 다음 굽기가 **새 이름 폴더**로 간다 (옛 폴더는 남음) |
| 맵 지우기 | Hierarchy에서 `Map_…` 삭제. 구운 파일은 남는다 → 필요 없으면 Project에서 `Art/Map/Baked/<이름>` 폴더도 지운다 |

- 비교용 카메라·치비·상자·연못은 작업 대상 맵의 가운데·동쪽 끝으로 자동으로 옮겨진다

## 5. 칸 크기 맞추기 (모든 맵 공용)
1. 도구 창 **칸 크기 → "한 칸 (m)"** 슬라이더 또는 후보 버튼 (2.133 / 1.067 / 1 m)
2. 모든 맵의 칠한 칸·구운 바닥과 비교 오브젝트 위치가 바로 맞춰진다 (값은 `Data/Tiles/TileMapConfig`에 저장)
3. 이미 구운 맵은 **다시 구워야** 게임 씬 프리팹에 반영된다 (다르면 노란 경고)
- 텃밭 로직 칸(`FarmConfig` Cell Size 1 m)과 맞추는 일은 칸 크기를 확정한 뒤 따로

---

## 6. 굽기 (작업 대상 맵만)
1. 구울 맵을 작업 대상으로 고른다 (도구 창 맨 위 "작업 대상: <이름>" 확인)
2. **"충돌체 함께 굽기"** 체크 확인 (맵마다 저장, 기본 켬)
   - 켬: 칠한 범위만 한 **BoxCollider**(윗면 = 바닥 높이 y 0, 두께 0.5 m)가 프리팹에 들어간다 → 게임 씬에서 `Ground` 상자 없이 바로 밟고 걷는다
   - 끔: 보이는 바닥만 (충돌은 씬의 다른 오브젝트가 맡을 때)
   - 두께는 `Data/Tiles/TileMapConfig`의 Collider Thickness
   - 충돌체는 **칠한 칸의 바깥 사각형** 전체를 덮는다 (안쪽에 빈칸이 있어도 막힘). 그 밖은 바닥이 없어 떨어진다 → 맵 가장자리 처리는 따로 (걸을 수 없는 경계)
3. **"굽기: <이름>"** 클릭
   - 이전 결과가 있으면 **덮어쓸지 묻는다** (프리팹 GUID는 유지 → 게임 씬에 이미 놓은 바닥도 자동으로 새 결과로)
   - 끝나면 결과 줄에 칸 수·타일 종류·조각 수·아틀라스 크기·**바닥 종류 수**·**충돌체 크기(m)**가 나온다. "표에 없는 칸"이 보이면 7장
   - 보기가 "구운 바닥"으로 바뀐다
4. 결과: `Art/Map/Baked/<이름>/`

   | 파일 | 용도 | 게임에서 |
   |---|---|---|
   | `<이름>_Floor.prefab` | **게임 씬에 놓는 바닥** (메시 + 머티리얼 + 바닥 종류 찾기 + 충돌체) | 씀 |
   | `<이름>_Atlas.png`, `<이름>_Floor.mat`, `Meshes/` | 프리팹이 쓰는 그림·재질·조각 메시 | 프리팹이 씀 |
   | `<이름>_Surfaces.asset` | 칸마다 바닥 종류 (발밑 파티클 등) | 프리팹이 씀 |
   | `<이름>_Cells.asset` | 칸마다 칠한 타일 (다시 불러오기용) | 안 씀 (에디터 전용) |
5. **Ctrl+S**로 씬 저장

## 7. 바닥 종류 (발밑 파티클 등)
- 굽기 때 칸마다 **바닥 종류**(풀·흙·진흙·짚·돌·나무판)가 함께 구워진다. 경계 칸은 칠한 재료로 친다 (흙 Rule Tile 경계 칸 = 흙)
- **표 고치기**: 도구 창 굽기 영역 **"바닥 종류 표 → 열기"** → Inspector에서 줄마다 타일·종류를 바꾼다. 고친 뒤 **다시 굽기**
- **종류 더하기**: Project에서 `Create > VoxelMagic > Tiles > Ground Surface`로 새 종류(예: 모래)를 만들고, 표에 줄을 더한다
- 새 타일 팩·타일을 추가했으면 메뉴 `바닥 종류 표 만들기·채우기 (farm)`를 다시 실행 (빠진 줄만 더함, 고친 줄은 그대로). 이름 규칙으로 못 정한 타일은 콘솔 경고 → 표에 직접 넣는다
- **확인**: 에디터 씬에서 플레이 → 왼쪽 위에 **"발밑 바닥: 흙 (x, z)"**. 플레이 중 Hierarchy에서 `Compare/Center/Chibi`를 끌어 옮기면 바뀐다
- **코드에서 쓰기** (나중에 플레이어 걸음에 붙일 때):
  ```csharp
  if (GroundSurfaceQuery.TryGet(발위치, out GroundSurface surface))
  {
      // surface == 흙 에셋이면 흙 파티클 … (나중에 GroundSurface에 파티클 칸을 추가)
  }
  ```
  배열 한 칸 읽기라 매 걸음 불러도 가볍다 (10만 번에 약 14 ms 측정). 씬에 바닥 프리팹이 여러 개여도 이 한 줄이면 된다

## 8. 게임 씬에 적용
1. 에디터 씬에서 **"충돌체 함께 굽기"를 켜고** 구운 맵인지 확인 (6장. 예전에 구운 맵은 다시 구워야 충돌체가 생김)
2. 게임 씬을 연다 (예: `Scenes/Prototype_FarmFishing`)
3. Project 창 `Art/Map/Baked/<이름>/<이름>_Floor.prefab`을 Hierarchy로 끌어다 놓는다
4. 위치 맞추기 (Inspector의 Transform)
   - 프리팹 원점 = 칸 (0,0)의 **남서쪽 모서리**, 바닥 높이 y = 0 → Position Y는 **0**
   - X·Z는 맵을 두고 싶은 곳으로. 예: 맵의 칸 (0,0)을 월드 (−20, 0, −20)에 두려면 Position = (−20, 0, −20)
   - **Rotation (0, 0, 0), Scale은 그대로** (Scale = 구운 칸 크기. 바꾸면 칸·바닥 종류 위치가 어긋남)
5. 기존 바닥 정리: 농장 씬의 40×40 `Ground` 상자는 **지우거나 끈다** (같은 높이라 깜빡이고, 충돌은 구운 바닥이 맡음)
   - 지우기 전에 확인: 플레이어·NPC·게시판·연못이 **칠한 범위 안**에 서 있는지 (범위 밖은 바닥이 없어 떨어진다)
6. **플레이로 확인**: 플레이어가 바닥 위에 서서 걷는지, 맵 끝까지 걸어 보기
7. 씬 저장 (Ctrl+S)
- 프리팹에는 메시·머티리얼·바닥 종류 찾기·충돌체만 있다 (Tilemap·Rule Tile 없음). 조명·그림자는 일반 3D 바닥처럼
- 맵을 고쳐 다시 구우면 게임 씬의 프리팹은 손대지 않아도 바뀐다 (충돌체 크기도 함께)
- 텃밭 로직 칸(`FarmConfig` Cell Size 1 m)과 타일 칸 크기가 다르면 심기 미리보기가 흙 칸과 어긋난다 → 같은 크기로

---

## 9. 구운 맵 다시 불러와 고치기
1. 도구 창 **구운 맵 불러오기** 영역
   - 구운 맵마다: `칸 수` → **[불러오기]** / `씬에 있음` → **[선택]** / `칸 데이터 없음` → 불러올 수 없음 (다시 구워야 생김)
   - 또는 Project 창에서 `<이름>_Floor.prefab`·`<이름>_Cells.asset`·맵 폴더를 고르면 **"Project에서 고른 맵 불러오기"** 버튼이 생긴다
2. 불러오면: 기존 맵들 옆에 `Map_<이름>`으로 칠한 칸이 그대로 되살아나고, 구운 프리팹이 연결되고, 칠하기 상태가 된다 (다른 맵 숨기기 옵션)
3. 고친 뒤 **굽기** → 같은 이름이라 덮어쓸지 묻는다 → 덮어쓰기
4. 다 고쳤으면 그 맵을 숨기거나 지워도 된다 (구운 파일·칸 데이터는 남아 언제든 다시 불러올 수 있음)

### 구운 뒤 잘못 칠했을 때: 구운 상태로 되돌리기
1. 그 맵을 작업 대상으로 고른다
2. 도구 창 굽기 영역 **"구운 상태로 되돌리기"** → 확인 창 **"되돌리기"**
3. 칠한 칸이 **마지막으로 구웠을 때**로 그 자리에서 바뀐다 (맵 위치·구운 바닥 그대로). 마음이 바뀌면 **Ctrl+Z**
- **잘못 칠한 채로 굽지 않는다** — 구우면 칸 데이터가 지금 상태로 바뀌어 되돌릴 기준이 사라진다 (덮어쓰기 확인 창에서 취소)
- 칸 데이터가 없는 맵(구운 적 없음, 처음 샘플 `FarmSample`)은 버튼이 꺼진다
- 몇 획만 잘못 칠했으면 그냥 Ctrl+Z로도 된다

## 10. 확인 도구
- **보기 전환**: 칠하기(Tilemap, 조명 없음) / 구운 바닥(조명·그림자 받음). 둘 중 하나만 보인다
- **해 높이·방향**: 이 씬 조명만 바뀐다. 농장 씬과 같은 값은 높이 50°, 방향 330°
- **플레이 모드**: 모든 맵에서 칠하기 층이 꺼지고 구운 바닥이 보인다 + 발밑 바닥 종류 표시

## 11. 문제가 생기면
| 증상 | 확인할 것 |
|---|---|
| 도구 창에 "타일 맵 에디터 씬이 아닙니다" | `타일 맵 에디터 씬 열기` |
| 칠해도 다른 맵에 칠해진다 | 작업 대상 확인 → "칠하기 시작"을 다시 누르기 |
| 칠한 칸과 구운 바닥이 겹쳐 깜빡인다 | 보기를 하나로 (칠하기 / 구운 바닥) |
| 굽기 결과에 "표에 없는 칸" | 콘솔 경고의 타일 이름을 바닥 종류 표에 더하고 다시 굽기 |
| 플레이 중 "발밑 바닥: 없음" | 그 맵을 구웠는지, 칠하지 않은 칸인지, 바닥 종류 기능 전에 구운 맵(예: 처음 샘플 `FarmSample`)인지 → 다시 굽기 |
| 새 맵 이름에 경고 | 같은 이름의 맵이나 구운 폴더가 있음 → 다른 이름 |
