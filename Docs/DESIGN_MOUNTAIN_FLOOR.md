> 범위: 바닥만. 나무·풀숲·돌·바위굴·바위벽·포획 구역은 제외 (나중에 사용자가 붙임)

## 1. 확인한 기준 (FarmPond 씬 직접 측정)
- 치비 키 1.63 m, 1복셀 0.0667 m. CharacterController 높이 1.8 / 반지름 0.35 / stepOffset 0.3 / slopeLimit 45°
- FarmPond 바닥(`FarmFishing_Floor`)은 20 × 26 m, 칸 1 m, 윗면 y = 0, 청크 5개. 화풍: 불투명 단색 복셀, 팔레트 1장
- `SM_Mod_Ground_Meadow.fbx`는 2 × 2 m, 두께 0.3 m (참고)

## 2. 규격
| 항목 | 값 |

| 복셀 1칸 | 0.0667 m (1 m = 15복셀), 정육면체 |
| 청크 | 16 × 16 m = 240 × 240복셀 (입장 꼬리 T만 6 × 5 m) |
| 원점 | 청크 왼쪽 아래 모서리, 배율 1, 회전 0 |
| 높이 | 바닥 윗면 절대 높이를 그대로 굽는다 (입구 y = 0), 배치는 (x, 0, z)만 맞추면 됨 |
| 단차 | 길 ±1복셀(0.067 m), 길 밖 최대 2복셀(0.13 m), 이웃 칸 단차 2복셀 이하 |
| 콜라이더 | FBX에는 넣지 않음 |
| 단면 | 바깥 둘레만 지형을 따라 22복셀(1.47 m): 윗 2복셀 윗면색, 그 아래 4복셀 `#4A3322`, 더 아래 `#3A281C`. 아랫면·안쪽 없음, B 북쪽 변은 열어 둠 |

## 3. 청크 (평면: +Z = 화면 왼쪽 위, +X = 오른쪽 위)
| 청크 | 위치 x0~x1, z0~z1 (m) | 역할 | 길 높이 (m) |
|---|---|---|---|
| T | 5~11, −5~0 | 입장 꼬리 | 0.0 |
| A1 | 0~16, 0~16 | 채집 구간 진입 | 0.0 → 1.0 |
| A2 | 0~16, 16~32 | 채집 구간 오르막 | 1.0 → 2.6 |
| A3 | 0~16, 32~48 | 채집 구간 능선길 | 2.6 → 4.1 |
| B | 0~16, 48~64 | 90° 꺾임, 북쪽은 포획 구역과 맞닿는 평지 (4.2 m) | 4.1 → 4.7 |
| C1 | 16~32, 48~64 | 2구간 | 4.7 → 6.1 |
| C2 | 32~48, 48~64 | 2구간 | 6.0 → 8.2 |
| C3 | 48~64, 48~64 | 2구간 | 8.2 → 10.3 |
| D | 64~80, 48~64 | 바위굴 앞 | 10.3 → 11.2 |

- 포획 구역 자리: B 북쪽 (0~16, 64~80). 청크 경계는 B의 북쪽 변, 높이 4.2 m 평지로 끝낸다
- 청크 사이 경계 높이는 한 함수에서 잘라 내므로 이음새에서 단차가 없다 (이웃 칸 단차 검증에 포함)

## 4. 길과 땅
- 길 폭 약 3 m(±0.3), 구불구불(진폭 약 2.7 m), 코너는 반지름 4 m 꺾임
- 길 경사 평균 8 %, 구간 0~20 % (최대 약 11°). 구간마다 오르막 뒤에 평지를 둠
- 단면: 길이 0.28 m 파인 길 + 산 쪽은 오르막(약 11°), 바깥쪽은 내리막(약 7°) + 바깥 끝은 흙 단면 테두리
- 색과 질감 (2026-11-10 수정: FarmPond 구운 바닥 아틀라스 `FarmFishing_Atlas.png`에서 읽은 값 기준, 단순하게)
  - 길: `#8A5A36` 한 색 + 드문 점(어두움 `#6B4428` 약 1 %, 밝음 `#A06C44` 약 1 %). **가장자리 1복셀을 외곽선색 `#4C321E`로** (FarmPond 길 외곽선과 같은 색)
  - 길 주변 흙: `#6A4A33` 한 색 + 드문 어두운 점 `#5B3F2B` 2.5 %. 연갈색 흙·낙엽 흙은 뺌
  - 이끼·풀 덩어리: 연못 이끼색 `#507848` + 어두운 점 `#386038` 3 % + 밝은 점 `#5F8A52` 1 %. FarmPond 풀(`#6F8F4A`)보다 어둡고 푸르게. 점 같은 잔 얼룩은 없애고 덩어리로만, 전체 면적 약 11 %
  - 흙 단면(바깥 테두리): `#4A3322`
  - 돌·풀숲·나무 없음. 길 가장자리 흙 번짐(디더) 없음
  - 색 수는 팔레트 11개 안팎

## 5. 제작 순서 (승인 후)
1. 높이장 → `.vox` 청크 생성 (스크립트, 청크마다 같은 함수에서 자름)
2. MagicaVoxel에서 열어 확인 → 내보내기 → Blender에서 원점·축·이름 정리 → FBX
3. Unity: `Art/Map/Mountain/` 에 청크 FBX + 팔레트 1장, 머티리얼 1개. 씬에 (x, 0, z)로 배치
4. 확인: 청크 이음새, 단차, 삼각형 수, 컬링

- 길 가장자리를 파인 길(0.28 m)로 할지
