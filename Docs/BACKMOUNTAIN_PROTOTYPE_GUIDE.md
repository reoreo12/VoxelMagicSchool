# 뒷산 채집/포획 프로토타입 지침 (Claude Code용)

> 프로젝트 `CLAUDE.md`에 붙이거나 `Docs/`에 저장하고 참조한다. 게임 구조, 코드 스타일, 입력/UI 방식은 **이 프로젝트의 기존 코드를 기준으로 맞춘다.** 이 문서는 무엇을 테스트할지만 정한다.

## 목적

새로 만든 뒷산 맵에서 **채집**과 **포획** 두 기능이 돌아가는지 기본 도형만으로 테스트한다. 오브젝트는 Cube/Sphere/Capsule/Cylinder와 단색 머티리얼로 만든다. 모델, 애니메이션, 이펙트, 사운드는 만들지 않는다. 관상 오브젝트, 굴 내부 씬, 도감, 점수, 저장은 범위 밖이다.

## 맵 (이미 제작됨, 수정 금지)

- 복셀 FBX 청크(16×16 m)를 이어 붙인 L자 지형이다. 복셀 1칸은 0.0667 m(치비와 동일)이고, 청크 FBX의 원점은 청크 왼쪽 아래 모서리다. 청크 배치 표의 (x, z)에 놓고 배율은 1이다. 머티리얼은 팔레트 1장을 공유한다. 배치 표가 프로젝트에 있으니 찾아서 쓴다.
- **FBX에는 콜라이더가 없다.** 이번 테스트는 청크에 **Mesh Collider를 직접 붙여** 등반해보고, 등반이 불가능하다고 전달받으면 경사 보조용 비스듬한 Box Collider를 깐다.
- 구간은 입장 꼬리 T → A1 채집① 진입 → A2 채집② 오르막 → A3 채집③ 능선길 → B 90° 꺾임 → C1~C3 → D 굴 앞이다. 길 높이는 0 m에서 약 11 m까지 오르고, 길 폭은 약 3 m, 길 전체 길이는 약 135 m다.
- 단차와 경사: 길 위 한 단은 1복셀(0.067 m), 평균 경사 8%, 구간별 최대 약 20%(약 11°)다. 컨트롤러는 높이 1.8 m, 반지름 0.35 m, `stepOffset` 0.3 m다. 설계상 경사 콜라이더 없이도 걸리지 않아야 한다.
- 이끼/풀 초록 덩어리가 곳곳에 있고, 돌, 풀숲, 나무는 맵에 없다. 이번 프로토타입에서 올리는 도형이 전부 새 오브젝트다.
- **포획 구역과 바위굴 자리는 맵에서 제외돼 있다.** 포획 구역은 B 구간 북쪽에 평지(높이 약 4.2 m)로 비어 있으니, 이번에 **프로토타입용 평평한 바닥을 직접 만들어 높이를 맞춘다.** 바위굴은 만들지 않는다. 구간 경계의 흰 선은 표시용 그림이다.

## 작업 방식

- 각 단계마다 만든 것과 **플레이 모드에서 확인한 것**을 짧게 보고한다. 확인하지 못한 것은 확인하지 못했다고 쓴다.
- 정해지지 않은 값은 Inspector 변수로 열고, 기본값은 "가정"이라고 알린다.
- 기존 맵 청크는 수정하지 않는다. 테스트 오브젝트는 `[Prototype]` 부모 아래에 모아 한 번에 지울 수 있게 한다.
- 코드를 쓴 뒤 콘솔 에러/경고를 확인한다. 질문은 한 번에 하나씩 한다.

## 1. 플레이어 등반

- 기존 플레이어를 T 구간 시작점(길 높이 0 m)에 둔다. 끝까지 걸어 올라가 보고, 걸림, 튕김, 낙하, 못 올라가는 구간이 있으면 **위치(구간 이름), 현상, 원인 후보**를 보고한다. 고치는 방법은 내가 고른 뒤에 한다.

## 2. 기존 시스템 복사
- 기존 플레이어가 FarmPond 씬에서 사용하던 농작물 수확 상호작용, 점수 UI, E 상호작용 UI, 낚싯감 정보 UI 등 기존에 이미 존재하는 틀이 있다면 BackMountain 씬에서 가져다 써도 된다.
- FarmPond 씬의 의뢰 게시판과 의뢰를 완료할 크리처 도형도 그대로 가져다 의뢰 목록만 뒷산에 맞게 바꿔 사용한다.

## 2. 채집

- **서식지**: 맵에 반복 배치하는 기본 도형 프리팹 4종(큰 나무 밑 그늘, 덤불, 바위틈, 초입 평지)이다. 각각 재료가 놓일 슬롯(자식 Transform) 몇 개를 가진다. A1~A3 길 양옆에 둔다. 몇 개를 어디에 놓을지 안을 먼저 보여 주고 확인받는다. 맵 높이가 구간마다 다르니 오브젝트는 지면에 맞춰 놓는다.
- **재료**: 눈에 보이는 상태로 슬롯에 놓인다. 재료마다 자기 서식지에만 난다. 재료는 시간대 태그가 있다. (추후 밤 시간대를 만들면 밤 시간대에만 나오는 재료들을 제작할 예정)
- **스폰**: 현재는 테스트용으로 키보드 키 하나를 디버그 키로 지정해, 키를 누르면 뒷산에 배치된 채집 재료의 위치와 종류가 랜덤하게 변경되도록 한다. (추후 변경안: 하루 시작(방과후)과 시간대 전환(방과후 -> 밤) 때 다시 스폰한다. 같은 서식지의 **다른 슬롯**으로 옮긴다. 현재 의뢰에 필요한 재료는 방과후와 밤 각각 최소 1개가 맵에 있도록 보장한다.)
- **줍기**: 가까이 가면 "E: 줍기" 안내가 뜨고, E로 줍는다.
- **의뢰**: 테스트용으로 하나를 디버그 키로 교체한다. 요구량은 최대 3개이고(예: 버섯 1개 / 같은 재료 3개 / 서로 다른 재료 2종), 재료 이름과 서식지 힌트 한 줄("그늘진 큰 나무 아래에서 자란다")만 보여 준다. 정확한 위치는 알려 주지 않는다. UI는 기존 씬의 의뢰 목록 UI를 함께 사용한다.
- 디버그 키: 디버그 키들은 화면 왼쪽 아래 모서리에 늘 간단한 안내 UI를 띄워둔다.

## 3. 포획

- **구역**: B 북쪽 평지에 트리거 영역과 황금빛 풀 바닥을 만든다. 개별 풀숲 약 10~12개를 흩어 놓는다(한 덩어리 아님). 입구 근처에 "산 동물 조심" 팻말을 세운다. 구역 안에서만 포획 로직이 돈다.
- **지나갈 때**: 플레이어 앞쪽 가장 가까운 풀숲 하나가 짧게 흔들린다. 동물은 없고 상호작용도 안 된다.
- **입질**: 구역 안에서 서서 기다리면 **5초 간격**으로 흔들리지 않는 풀숲 한두 개가 무작위로 흔들린다(그 풀숲에 오는 동물도 무작위). 일정 시간 흔들리다 멈추면 동물이 사라진 것이다. 빈 입질은 없다. 흔들림 지속 시간과 동시 흔들림 수는 Inspector에서 조절한다.
- **구역 이탈**: 새 입질은 멈추고, 이미 흔들리는 풀숲만 끝까지 흔들리다 멈춘다.
- **포획**: 흔들리는 풀숲 가까이에서 E를 누르면 마법진 그리기에 들어간다. 이번에는 실제 그리기 없이 **스텁**으로 대체한다(정확도를 반환하고, 디버그 키로 성공/실패를 강제할 수 있다). 도안은 하나다. 결과는 성공/실패 이분법이고, 동물 데이터의 요구 정확도 이상이면 성공이다. 실제 마법진으로 교체하기 쉽게 만든다.
- **결과**: 성공하면 화면 정중앙에 "OOO 포획!"을 띄우고 인벤토리에 넣는다. 실패하면 "놓쳤다"를 띄우고 풀숲 흔들림을 멈춘다.

## 필요한 UI (최소)

- 이미 존재하는 인벤토리 퀵슬롯 5칸(같은 종류는 한 칸에 개수로 누적, 채집 재료와 포획 동물이 같이 쓴다). 새 종류가 들어갈 칸이 없으면 안내만 하고 획득하지 않는다(잠정).
- "E: 줍기" / "E: 포획" 상호작용 안내.
- FarmPond 씬의 낚싯감 정보 UI와 같은 획득/포획/실패 문구.
- 이미 존재하는 의뢰 목록 UI에 채집/포획도 현재 의뢰와 진행도 표시(재료 이름, 서식지 힌트, 요구량).
- 디버그 패널(현재 구현 X, 후반부 구현): 현재 시간대, 포획 구역 안/밖, 다음 입질까지 남은 시간, 흔들리는 풀숲 수. 디버그 키는 시간대 전환, 새 하루 시작, 의뢰 교체, 인벤토리 비우기, 입질 즉시 발생, 마법진 성공/실패 강제다.

## 확인할 것

- L자 길을 끝까지 걸을 수 있다. 문제 구간을 기록했다.
- 재료가 자기 서식지에만 나고, 밤 전용은 방과후에 안 나온다. 새 하루에 다른 슬롯으로 옮겨진다. 의뢰 재료가 시간대마다 1개 이상 있다. 줍기와 누적이 된다.
- 구역 밖에서는 포획 로직이 안 돈다. 지나갈 때 앞 풀숲이 흔들린다. 서 있으면 8초마다 입질이 오고, 흔들림이 멈춘다. 구역을 나가면 새 입질이 멈춘다. 포획 성공/실패가 처리된다.
- 콘솔에 에러가 없고, 기존 맵 청크는 바뀌지 않았다.
