# 플레이 테스트 안내 — 프로토타입 1 (의뢰 · 농사 · 낚시)

## 시작하기
1. `Assets/_Project/Scenes/Prototype_FarmFishing.unity`를 연다.
2. ▶ 플레이를 누른 뒤 **Game 뷰를 한 번 클릭**한다. (포커스가 없으면 키 입력이 들어가지 않는다)

## 조작
| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 (화면 위쪽 = W) |
| E | 상호작용 / 대사 넘기기 / 입질 전 낚싯대 거두기 / 입질 잡기 / 결과 중 다시 던지기 |
| 1~5, 칸 클릭 | 인벤토리 선택 |
| 마우스 스크롤 | 낚시 미니게임 잡기 바 이동 |
| Q | 의뢰 진행 접기/펼치기 |
| Esc | 창 닫기 / 낚시 취소 |

## 완료 기준 시나리오 따라 하기
1. 화면 확인: 위쪽 점수(실기 0/100, 필기 0/100), 왼쪽 아래 조작법, 아래 인벤토리 1번 칸 **지팡이**.
2. 학교 앞 **게시판**(갈색 판)으로 가면 `E / 의뢰 보기` → E → **"국물 재료가 필요해"** 수락.
3. 인벤토리 2번 칸에 대파 씨앗 2개, 오른쪽 위에 `□ 대파 0/2`, `□ 붕어 0/1`.
4. **2**를 눌러 대파 씨앗을 들고 **텃밭**(갈색 칸) 위에서 바라보는 칸에 초록 미리보기가 보이면 E. 옆 칸에도 한 번 더 심는다. (빨강이면 자리가 없다는 뜻)
5. **1**(지팡이)을 들고 새싹 앞에서 E → 바로 자란다. E로 뽑으면 위쪽에 획득 정보가 3초 뜬다(움직이면 바로 닫힘). 두 개 다 뽑으면 `■ 대파 2/2`.
6. 지팡이를 든 채 **연못** 가에서 E → 머리 위 **"!"** 가 뜨면 1초 안에 E → 오른쪽 미니게임에서 **스크롤**로 초록 바를 물고기에 맞춰 게이지를 채운다. 붕어가 나올 때까지 반복 (획득 정보가 떠 있을 때 E = 바로 다시 던지기, 입질 오기 전 E = 낚싯대 거두기). 출현 비율: 붕어 60 · 메기 30 · 번개 붕어 10.
7. **크리처**(남색 큐브, 노란 눈)에게 가면 `E / 전달하기` → 대사를 E로 넘긴다 → 위쪽 필기 바가 **25**까지 차오른다.
8. 게시판에서 다른 의뢰를 수락할 수 있다. 의뢰 진행 중에는 다른 의뢰의 수락 버튼이 꺼져 있다.

## 조절할 수 있는 값 (인스펙터에서 수정)
| 무엇 | 에셋 |
|---|---|
| 인벤토리 칸 수, 점수 상한·새 재료 보너스, 획득 정보/알림 표시 시간, 점수 바 속도, 완료 표시 시간 | `Data/Config/GameBalanceConfig` |
| 텃밭 격자 크기·칸 크기, 앞 칸 거리, 미리보기 색, 성장 연출 시간 | `Data/Config/FarmConfig` |
| 던지기·대기·입질 시간, 놓치면 재대기, 스크롤 감도, 잡기 바 크기, 게이지 시작·증가·감소, 물고기 출현 비율 | `Data/Config/FishingConfig` |
| 이동 속도, 회전 속도, 상호작용 반경, 카메라 거리·각도·따라가기 | `Data/Config/PlayerConfig` |
| 아이템 이름·설명·색·크리처 설명, 작물 크기 범위, 씨앗 칸 크기, 물고기 움직임 | `Data/Items`, `Data/Seeds`, `Data/Fish` |
| 의뢰 이름·대사·필요 아이템·지급 씨앗·보상 | `Data/Requests` |
| 화면 문구 | `Scripts/Core/Common/GameTexts.cs` |

> 씬은 메뉴 **VoxelMagic → 프로토타입 씬 다시 만들기**로 재생성된다. 씬을 직접 고치면 재생성 시 사라지므로, 배치 변경은 `PrototypeSceneBuilder`에 반영한다. 데이터 에셋은 재생성해도 덮어쓰지 않는다.
