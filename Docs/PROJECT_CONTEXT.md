## 3. 비버 가구점 타이쿤 (요약)

- Notion: https://app.notion.com/p/406e0b227bb681ec912ce0e7e826fd10
- 출발점 페이지: "내가 좋아하는 것으로부터 게임 설계해보기 - 비버 가구점 타이쿤" (수업 과제. 귀여운 동물 캐릭터 + 육성과 보상으로 애착을 쌓는 타이쿤)

### 기본 정보 (모두 [잠정])
- **장르**: 스타듀밸리 계열 생활 시뮬레이션 + 농사 + RPG. 직업, 농사, 마을 생활, 의뢰, 던전 탐험·전투
- **톤**: 기본은 따뜻하고 밝음. 오프닝·과거 사연·던전에서 어두운 면
- **비주얼**: Stylized 3D + Mid Poly, 따뜻한 셰이더. 콩눈 같은 단순한 이목구비, 덩어리감 있는 조형
- **핵심 루프**: 자연에서 자원 채집 → 직업 활동·농사·의뢰 → 마을 발전 → 던전 해금·탐험·전투
- **하루 구조**: 낮에는 생활·가게 운영, 밤에는 선택적으로 던전 (문라이터 참고). 잠은 의무가 아닌 선택
- **플레이어**: 사람에게 고통받다 도망쳤거나 버려진 동물. 폐허를 마을로 가꿈
- **주인공**: 비버 — 목수 / 가구점 사장. 직접 키운 나무를 갉아 의뢰받은 가구를 만든다 (완성도 = 크기·모양 유사성·소재). 사연: 사람의 공사로 터전을 잃고 인부에게 쫓겨남
- **플레이어블**: 동물 종류에 따라 직업만 달라지는 구조 (잠정). 후보: 딱따구리(가구점 공동 운영·라이벌), 라쿤(고물상), 바우어새(인테리어), 다람쥐(잡화점), 스핑크스 고양이(옷가게), 고슴도치(미용사), 나무늘보(배달부), 흰 토끼(약초상, 무거운 소재 주의)

### 세계관 요점
- **역사**: 현실과 비슷한 현대 세계. 버려진 동물들의 종착지 같은 폐허가 있음. 오프닝 = 사연 컷씬 → 밤의 숲에서 무언가에 쫓겨 폐허로 도망(이동 튜토리얼) → 폐허를 가꾸는 튜토리얼
- **지리**: 마을(폐허) + 주변 자연 + 던전. 던전은 마을이 발전하면 해금되고, 멀수록 사람의 영역(첫 던전 숲·동굴 → 먼 던전 사람 마을·건물)
- **정치**: 사람은 던전의 적. 상처받아 온 사람 주민이 있을 수 있음(말이 잘 안 통함)
- **경제**: 자원은 대부분 자연. 사람의 물건·특수 재료는 던전에서 구함
- **마법/기술**: "어둠" = 숲에 찾아오는 밤과 그 속의 존재(눈이 빛나고 짐승·사람 소리를 냄). 사람 기술은 현대 수준
- **[미정]**: 폐허의 기원(제안 2 옛 동물 마을 / 제안 3 자연의 성역), 종교, 화폐·교역, 멀티플레이, 이족/사족보행
- **확인 필요**: 사람이 적인데 사람 주민이 있는 이유, 사람들이 말하는 동물 마을을 아는지

### 수업 과제에서 나온 디테일
- 육성: 이빨 강화 등 / 보상: 비버 집 꾸미기, 이동수단
- 메인: 가구점 운영·확장, 큰 의뢰(지자체), 딱따구리 라이벌 가구점 / 서브: 조각 콘테스트, 친밀도
- 주민 특성을 살린 의뢰 예: 고양이의 고층 가구, 하마의 대형 욕조, 날지 못하는 오리의 고층 의뢰
- 엔딩: 비버와 주민들의 상처가 모두 치유되어야 함

## 4. 복셀 한국 마법 학교 게임 / Voxel Magic School (요약)

- Notion: https://app.notion.com/p/406e0b227bb681c08155ce37e0ab0e2f
- 제작 조건: 1인, 집중 1개월(총 3개월), Claude Code와 개발, 포트폴리오 영상 목적. 아트는 복셀 통일, 캐릭터는 VARCO 3D로 생성·리깅

### 핵심 (대부분 [잠정])
- **설정**: 지금의 한국과 같은 세상에 마법이 오래전부터 있었고 어디서든 합법. 학교는 단계형 **마법 급수 시험**을 위해 마법을 가르침. "흑마법"은 소문일 뿐이고 실체는 라면을 불게 하는 정도의 하찮은 마법
- **주인공**: 마법 열등생 고등학생. **8일째(D-Day)** 급수 시험을 앞두고 뒷산 크리처(한 마리, 밤에만 활동)에게 몰래 과외를 받음
- **코어 루프**: 방과 후 재료 모으기(텃밭 농작·호수 낚시·뒷산 채집) → 밤에 크리처 굴에서 과외(실기 점수, 하루 하나, 진도제) + 의뢰 전달(필기 점수, 마법 재료학) → 8일째 시험. 화폐 대신 **시간**이 자원
- **지리**: 주인공의 방 / 학교(허브) / 텃밭·호수 / 뒷산(인적이 드문 곳) / 크리처 굴(의뢰 게시판이 굴 안). 학교 외부는 3D 쿼터뷰, **학교 복도만 2D 횡스크롤**
- **입력**: 음성 주문(Whisper 로컬 + 자모 유사도) / 마법진 그리기(챔퍼 거리 유사도). 마이크 없는 환경을 위한 HUD 모드 대안
- **포획**: 게임에 넣을지 **보류** (11-24). 의뢰 재료에서도 제외
- **아이디어로만 남긴 것**: 밤에만 나오는 생물·물고기, 경비원이 밤의 뒷산까지 오는 것

### 8일 일정 (B안, 11-13)
| 날짜 | 표시 | 낮·방과 후 | 밤 (정석) |
|---|---|---|---|
| 1일 | D-7 | 첫 수업(무 개그) → 소문 | 크리처와 만남 + 빛 + 튜토리얼 의뢰 |
| 2일 | D-6 | 자유 | 의뢰 + 느려져라 |
| 3일 | D-5 | 아침 지각 레이스(3인칭 스쿠터) → 자유 | 의뢰 + 찾아라 |
| 4일 | D-4 | 점심 불량배 대결(1인칭 슈팅, 느려져라로 공략) → 자유 | 의뢰 + 숨어라 |
| 5일 | D-3 | 낮 석고상 보스전(3인칭, 먼지 속 석고상을 찾아라 실루엣으로) → 자유 | 의뢰 + 불꽃 |
| 6일 | D-2 | 자유 | 마지막 의뢰 전달 + 과외(만회용) |
| 7일 | D-1 | 방과 후 축제 구경(에셋 여유 시) | 불꽃 축제 (과외·의뢰 없음) |
| 8일 | D-Day | 급수 시험 → 엔딩 | |
- **주문 5개**: 빛 → 느려져라 → 찾아라(유일한 마법진 주문, 실루엣 표시) → 숨어라 → 불꽃. "자라라" 삭제 → 작물은 물을 줘야만 자람 (11-25: 게임 시간으로 흔함 3시간·보통 5시간·희귀 다음 날 아침)
- **무 개그**: 첫날 수업, 그리고 불꽃을 못 배운 채 맞은 축제(무 모양 불꽃, 손해 없음) 두 곳에서만. 시연 영상은 성공/무 불꽃을 나란히 또는 이어서
- 이벤트마다 필요한 주문을 배운 뒤 하루 여유가 있어 과외를 한 번 빠져도 만회 가능

### 의뢰 시스템 (11-24)
- 플레이어가 골라 계획하는 할 일 목록. **굴 안 게시판**, 하루 시작 때 새 의뢰 3개(안 받은 건 사라짐), **동시에 3개까지** 보관, 전달해야 칸이 빔
- 재료 최대 3개 + 서식지 힌트, 재료를 모두 모아야 제출. 크리처와 대화하면 완료할 의뢰를 골라 하나씩 대사와 함께 전달(겹치는 재료는 고르는 순서로 해결)
- 포기: 의뢰 목록 UI / 책 메뉴 의뢰 상세 페이지 버튼. 보상은 필기 점수만, 수락 시 필요한 씨앗 지급(버리면 재지급)
- 필기 점수는 재료 개수·희귀도로 차등(처음 가져온 재료 우대 삭제). 재료 하루 보장 없음(튜토리얼 제외)
- 튜토리얼(1일 밤): 크리처가 빛 스포트라이트로 따라다님, 시간 정지, 농작 → 낚시 → 채집 순서, 결과 보장
- Claude 제안값: 게시판 쉬움·보통·어려움(어려움은 3일부터) / 점수 흔함 2·보통 4·희귀 8 / 채집·낚시 희귀도 60·30·10%, 서식지마다 자리 8곳 중 4곳
- 11-25 추가: 게시판 반복 방지(최근 2일 게시 제외, 덜 게시된 의뢰 우선), 희귀 작물 의뢰는 5일까지만 게시, 게시판·전달은 밤에만, 의뢰 19개(튜토리얼 1 + 쉬움·보통·어려움 각 6)

### 타이머 (11-24)
- 목표 플레이 약 **1시간**. 방과 후 16:00~20:00(현실 3분 30초) + 밤 20:00~24:00(2분 30초) = 하루 약 6분, 시간이 흐르는 날은 2~6일
- 하루 시작 = 방과 후 시작(작물 성장 → 채집 재생성 → 게시판 교체). 경고 19:40·23:40(11-25, 20분 전). 24:00 미귀가 = 경비원 발각 → 다음 날 17:00 시작. 이벤트 결과로 15:30/16:30/17:00
- 멈춤: 책·가방·패널, 크리처 대화·과외, 스토리·이벤트, 맵 이동(페이드) 중. 흐름: 걷기·낚시·마법진. 채집 줍기는 시간 소모 없음. 시간대 화살표는 시간에 따라 부드럽게 회전
