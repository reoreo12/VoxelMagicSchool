# 아바타 넣기 안내 — 모델 · 애니메이션 · 복도 캐릭터

이 틀만 지키면 새 아바타(여학생, NPC 등)와 새 애니메이션을 메뉴 몇 번으로 적용할 수 있다.

## 1. 파일 넣기 (틀)
```
Assets/_Project/
├─ Art/Characters/<캐릭터>/      한 캐릭터의 것은 전부 여기 (폴더 이름 = 아바타 이름)
│  ├─ Model/                     3D 모델 .fbx + 텍스처 .png
│  └─ Sprites/                   2D 스프라이트 (아틀라스 + .json)
└─ Animations/<아무 폴더>/        애니메이션 .fbx (예: Mixamo/Y Bot@Walking.fbx) — 모든 캐릭터가 같이 씀
```
- 한 캐릭터 폴더에 모델이 여러 개(버전 비교 등)면 아바타 이름은 **파일 이름**이 된다 (`Student_Male_v03.fbx` → `Data/Avatars/Student_Male_v03`). 이미 아바타가 있는 모델은 그 아바타를 갱신한다.
- 모델: 사람 뼈대(골반·척추·머리·팔 3마디·다리 3마디)가 있어야 한다. 정면은 +Z. 이 폴더의 .fbx는 모두 캐릭터로 처리되므로 소품 모델은 다른 폴더에 둔다.
- Mixamo 애니메이션: FBX for Unity, **Without Skin**, 30fps. 걷기·달리기는 **In Place** 체크.
- 클립 이름은 파일 이름의 `@` 뒤가 된다 (`Y Bot@Walking.fbx` → `Walking`). 이름에 idle / walk / run(sprint, jog)이 들어가면 상태에 자동 연결된다.

## 2. 메뉴 실행 (Project 창에서 선택 → 메뉴 `VoxelMagic/아바타/`)
| 순서 | 선택할 것 | 메뉴 | 결과 |
|---|---|---|---|
| ① | 애니메이션 .fbx (또는 폴더) | 2. 선택한 애니메이션 Humanoid로 임포트 | Humanoid, 반복 재생, 루트 이동·회전을 포즈에 굽기 |
| ② | 모델 .fbx | 1. 선택한 캐릭터 모델 준비 | Humanoid, 키 1.6에 맞춘 배율, 텍스처 Point, `Data/Avatars/<이름>` 생성 + Idle/Walk/Run 자동 연결 |
| ③ | `Data/Avatars/<이름>` | 3. 선택한 아바타로 복도 캐릭터 만들기 | Controller·프리팹 생성, 복도 캐릭터로 지정, 복도 씬 다시 만들기 |

- 애니메이션을 먼저(①) 임포트해야 모델 준비(②)에서 자동 연결된다. 순서가 바뀌었으면 `Data/Avatars/<이름>`에서 클립을 직접 연결하고 ③을 다시 실행.
- 키를 바꾸려면 `Data/Avatars/<이름>`의 목표 키를 고치고 ②를 다시 실행.
- 큐브 캐릭터로 되돌리려면 `Data/SideScroll/CorridorConfig`의 캐릭터 프리팹을 비우고 `VoxelMagic/복도/복도 씬 다시 만들기`.

## 3. 애니메이션 랩에서 확인 (`Scenes/Sandbox/AnimationLab.unity`)
- 플레이 → Game 뷰 클릭. 왼쪽 위에서 아바타 선택, 오른쪽 목록에서 클립 클릭.
- **새 모델은 메뉴 없이도 된다**: `Art/Characters/` 아래에 아바타 데이터가 없는 .fbx가 있으면 랩을 시작할 때(또는 **새로고침**) 자동으로 ② 처리를 하고 왼쪽 위 목록에 추가한다. 아래쪽 안내에 추가된 이름이 뜬다.
- 새 애니메이션 파일을 넣었으면 **새로고침**. Humanoid가 아닌 .fbx는 목록에서 눌러 바로 임포트할 수 있다.
- 확인할 것: 키 비교 큐브와 키가 맞는지 / 반복 재생 이음매 / 클립 사이 섞기(A↔B 반복 전환, 섞기 시간) / 골반 이동 폭 "(제자리)" / 여러 각도(정면·옆·뒤·3/4).
- **버전 비교**: 비교할 모델마다 ② 메뉴를 실행한 뒤 랩 왼쪽 위 목록에서 번갈아 고른다. 바꿔도 재생 중인 클립·시간·일시정지·카메라가 그대로 이어져, 같은 순간을 바로 비교할 수 있다 (일시정지 + 프레임 이동 추천).
- **도트 렌더링**: 재생 패널 오른쪽 토글(P)로 켜고, 슬라이더로 도트 크기(2~8배)를 바꾼다. 화면을 낮은 해상도로 그려 확대하므로 UI는 선명하게 남는다. 가는 선(바닥 격자)은 도트가 클수록 끊겨 보인다.
- 모델 파일을 다시 복사해 넣어 Humanoid 설정이 풀린 경우에도, 랩 시작·새로고침 때 자동으로 다시 준비한다.
- 단축키: Space 재생/일시정지, ←/→ 한 프레임, 1/2/3 Idle/Walk/Run, L 반복, P 도트 렌더링.
- 랩 화면 구성을 바꿨으면 메뉴 `VoxelMagic/아바타/애니메이션 랩 씬 다시 만들기`.

## 4. 복도에서 속도 맞추기
- 복도 씬을 플레이한 채로 `Data/Avatars/<이름>`의 **Idle/Walk/Run 재생 속도**를 바꾸면 바로 반영된다 (플레이를 멈춰도 값이 남음).
- 시작값: 랩의 "디딤발 속도"가 알려 주는 제안 값 (재생 속도 ≈ 게임 이동 속도 ÷ 디딤발 속도).
- 이동 속도 자체(조작감)는 `Data/SideScroll/CharacterMoveConfig`.
